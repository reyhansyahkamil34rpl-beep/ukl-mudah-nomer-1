# ukl-mudah-nomer-1
Scanner → Digunakan untuk membaca input dari keyboard.
NumberFormat → Untuk memformat angka menjadi bentuk mata uang.
Locale → Untuk menentukan format Indonesia (Rp).
public class BiayaPengiriman → Nama kelas program.
main() → Titik awal eksekusi program.
Membuat Objek Scanner Untuk mengambil input pengguna (berat, jarak, panjang, lebar, tinggi).
try → bagian utama program dijalankan.
finally → menutup Scanner untuk mencegah kebocoran resource.try → bagian utama program dijalankan.
Jika jarak ≤ 10 km → biaya Rp 4250 per kg
Jika jarak > 10 km → biaya Rp 6000 per kg
Biaya dihitung berdasarkan:
berat (kg) × biaya per kg
Jika volume lebih besar dari 100 cm³ → tambah biaya Rp 50.000
final → nilai konstan (tidak bisa diubah)
Output akan menampilkan:
 Berat paket
 Jarak
 Volume
 Biaya per kg
 Biaya tambahan volume
 Total biaya bayar
